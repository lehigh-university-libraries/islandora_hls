# Islandora HLS

Create streaming audio and video derivatives

## Requirements

Install this module as normal in our Islandora repository `composer require drupal/islandora_hsl`

Also requires the [islandora/homarus](https://github.com/Islandora-Devops/isle-buildkit/tree/main/images/homarus) microservice (version `6.3.0` or above) to create the HLS derivatives
